# M4003_Quant_Analysis_25000145424

## Project Overview

This repository contains the code and datasets used for the quantitative analysis component of my mixed-methods research project:

**Research Question:**

"To what extent is AI reshaping task composition in UK digital professions, and how does this align with existing predictions of automation risk?"

The quantitative analysis investigates employment and labour demand trends across selected UK digital occupations between 2021 and 2024.

## Repository Contents

### employment_analysis.ipynb

Jupyter Notebook containing:

* Data cleaning and preparation
* Filtering of digital occupations
* Descriptive analysis
* Data visualisations
* Statistical analysis

### employmentby4digitsoc1digitindustryatosuk20212024final.xlsx

ONS employment dataset used in the analysis.

### labour_demand_dataset.xlsx

Labour demand / vacancy dataset used in the analysis.

## Reproducibility

The notebook and datasets included in this repository allow the quantitative analysis and figures presented in the accompanying academic report to be reproduced.
